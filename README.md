# 📝 Word Counter

A free, open-source online word counter. Count words, characters, sentences, paragraphs, and estimate reading time — all in your browser. No server, no signup.

**Live demo:** [vaultool.com/tools/word-counter.html](https://vaultool.com/tools/word-counter.html)

## ✨ Features

- **Word Count** — Accurate word counting for all languages
- **Character Count** — Total characters and characters without spaces
- **Sentence Count** — Split by punctuation marks
- **Paragraph Count** — Count text blocks separated by blank lines
- **Reading Time** — Estimate based on 200 words per minute
- **Word Frequency** — Top 15 most used words (excluding stop words)
- **Real-time** — All stats update as you type
- **Privacy First** — 100% client-side, your text never leaves the browser
- **Zero Dependencies** — Single HTML file, no build step required

## 🚀 Quick Start

Just open `index.html` in any modern browser. No installation needed.

## 🛠️ Tech Stack

- Vanilla HTML/CSS/JavaScript
- Zero dependencies
- No build tools required
